University Honors Program Requirements

This is a short summary of the requirements every college's Honors Program shares. It comes from the Iowa State University Honors Program Student Handbook.

  1. Keep a cumulative grade point average of 3.50 or higher.
  2. Take two honors courses (at least 5 credits total).
  3. Take two honors seminars.
  4. Submit an advisory program of study (POS) to your college's Honors Committee. Do this when you have five semesters left before graduation, usually the spring of your sophomore year.
  5. Complete an honors project. The project proposal is due one semester before you start (September 21 or February 21). Register for 1 to 4 credits of HON 4900A/B during the semester you finish your project.
  6. Present at the Honors Poster Session.

How to Use This Site

Getting started. Search for your major on the first screen and pick it. You can also add a second major, a minor, or Masters plans, or mark yourself as an Honors student. All of these are optional. Then click "Create a Schedule."

Your schedule (left column) starts pre-filled with an example pathway. Drag any course from the requirements list on the right into a semester to add it. Drag it off the schedule to remove it. Each course row has a "Pre/Co-reqs" button that shows what it needs and flags a red warning if something is still missing. It also has an "Add Grade" button for your own GPA tracking. Use "+ Add Summer Semester" or "+ Add Fifth Year" if your plan needs either one.

Requirements checklist (right column) lists every section of each program you picked. A green checkmark means that section is fully scheduled. The search bar above it searches courses, departments, and named requirement categories.

Changing your programs. Click "Edit Selections" at the top of the schedule screen any time. You can change your major, add or remove a second major, minor, or Masters, or toggle Honors. Each combination of programs keeps its own saved schedule.

Export / Import. "Export Schedule" saves your whole plan, including grades, as a CSV file or an Excel-openable file. "Import Schedule" reads one of those files back in. It only works with files this site exported. A plain .xlsx file saved from Excel is not supported.

Classes Connected (the other tab) shows every course as a dot. Courses connect to each other by prerequisite, corequisite, cross-listing, or being mentioned together. Bigger dots have more connections. Drag to pan, scroll to zoom, click a dot to pin it and highlight its direct connections, or search for a course by name.

About This Site

Hi, I'm Matthew Hawver, an Iowa State University student. I built this degree planner to make things easier. Here you can see a whole major's requirements, minors, and prerequisites in one place. You can lay out a real semester-by-semester schedule, and see how ISU's courses actually connect to each other. No more piecing it all together by hand from the course catalog and requirement sheets.

Open Source

Everything here is public on GitHub: the ISU catalog scrapers, the data pipeline that turns them into JSON, and this website itself. Take a look if you want to see how it works, or run it yourself.

README.md
Project overview and setup instructions. Start here.
PROJECT_DOCUMENTATION.md
The full technical write-up: every file, every feature, and how the data pipeline fits together.
run_full_update.py
One command that re-scrapes ISU's catalog and rebuilds the site's data, start to finish.
scrapers/
The Python scripts that pull majors, minors, Masters programs, and ~8,400 courses directly from ISU's course catalog.
data/
The scraped CSVs those scrapers produce. These are checked in, so the site can be built without re-scraping.
website/
The actual site: HTML/CSS/JS, plus the build scripts that turn data/'s CSVs into the JSON the browser loads.
