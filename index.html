University Honors Program Requirements

A condensed version of the requirements every college's Honors Program has in common (Iowa State University Honors Program Student Handbook).

  1. Maintain a cumulative grade point average of 3.50 or higher.
  2. Take two honors courses (minimum of 5 credits total).
  3. Take two honors seminars.
  4. Submit an advisory program of study (POS) to your college's Honors Committee when you have five semesters remaining before graduation (typically in the spring of your sophomore year).
  5. Complete an honors project; the project proposal is due one semester before the project (September 21/February 21). Register for 1-4 credits of HON 4900A/B the semester you complete your project.
  6. Present at the Honors Poster Session.

How to Use This Site

Getting started. Search for and pick your major on the first screen. You can also add a second major, a minor, Masters plans, or mark yourself an Honors student -- all optional -- before clicking "Create a Schedule."

Your schedule (left column) starts pre-filled with an example pathway. Drag any course from the requirements list on the right into a semester to add it, or off the schedule to remove it. Each course row has a "Pre/Co-reqs" button (shows what it needs, and flags a red warning if something's still missing) and an "Add Grade" button for your own GPA tracking. Use "+ Add Summer Semester" or "+ Add Fifth Year" if your plan needs either.

Requirements checklist (right column) lists every section of each program you picked. A green checkmark means that section is fully scheduled. The search bar above it searches courses, departments, and named requirement categories.

Changing your programs. Click "Edit Selections" at the top of the schedule screen any time to change your major, add or remove a second major/minor/Masters, or toggle Honors -- each combination of programs keeps its own saved schedule.

Export / Import. "Export Schedule" saves your whole plan (including grades) as a CSV or an Excel-openable file. "Import Schedule" reads one back in -- only files this site itself exported; a plain .xlsx saved from Excel isn't supported.

Classes Connected (the other tab) draws every course that connects to another -- by prerequisite, corequisite, cross-listing, or being mentioned together -- as a dot, sized by how many connections it has. Drag to pan, scroll to zoom, click a dot to pin it and highlight its direct connections, or search for a course by name.

About This Site

Hi, I'm Matthew Hawver, an Iowa State University student. I built this degree planner to make it easier to see an entire major's requirements, minors, and prerequisites in one place, lay out a real semester-by-semester schedule, and see how ISU's courses actually connect to each other -- instead of piecing all of that together by hand from the course catalog and requirement sheets.

This is an independent, unofficial student project -- not something built, run, or endorsed by Iowa State University. See the for details.

Open Source

Everything here -- the ISU catalog scrapers, the data pipeline that turns them into JSON, and this website itself -- is public on GitHub, if you want to see how it works or run it yourself.

README.md
Project overview and setup instructions -- start here.
PROJECT_DOCUMENTATION.md
The full technical write-up: every file, every feature, and how the data pipeline fits together.
run_full_update.py
One command that re-scrapes ISU's catalog and rebuilds the site's data, start to finish.
scrapers/
The Python scripts that pull majors, minors, Masters programs, and ~8,400 courses directly from ISU's course catalog.
data/
The scraped CSVs those scrapers produce -- checked in, so the site can be built without re-scraping.
website/
The actual site: HTML/CSS/JS, plus the build scripts that turn data/'s CSVs into the JSON the browser loads.
